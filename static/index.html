Discord Bot Commands

Interactive cheatsheet for all slash and prefix commands. Click any command to copy.

Default Prefix: !
/play <query or url> !play

Search YouTube or paste a URL to play audio in your voice channel.

/skip !skip

Skip the currently playing track and advance to the next song in queue.

/pause !pause

Pause voice channel audio playback.

/resume !resume

Resume paused music playback in voice channel.

/queue !queue

Display upcoming tracks in the current server queue.

/volume <1-100> !volume

Adjust playback volume level in Discord voice.

/stop !stop

Stop music, clear the queue, and disconnect bot from voice.

/panel !panel

Get the instant URL link to open this Web Dashboard.

Bot Configuration & Token

Quick Discord Bot Setup

  1. Go to Discord Developer Portal
  2. Create an Application > Click Bot tab > Reset/Copy Token
  3. Enable Message Content Intent & Server Members Intent
  4. Use the OAuth2 > URL Generator with scopes: bot, applications.commands and voice permissions (Connect, Speak).
